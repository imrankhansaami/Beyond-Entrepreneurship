# Reference — Official Jim Collins Tools (Personal Use)

These three PDFs are the official tool documents behind this system, downloaded from **jimcollins.com** and included here for your **personal (including intra-company) use**, with their copyright notices intact — the terms under which they are distributed permit exactly this. Do not redistribute them outside your company or sell them.

**Note on the Git repository:** the PDFs themselves are deliberately **excluded** from version control (see `.gitignore`) — distributing them via GitHub would go beyond the personal/intra-company use their terms allow. If you clone this repository and `reference/` contains only this README, download the three tools from jimcollins.com to restore your local set.

| File | What it is | Where it's used |
| --- | --- | --- |
| `the-map-twelve-questions.pdf` | **The Map: Twelve Questions for Building a Great Company** (© 2022 Jim Collins) — the 12 principles in 4 stages, with directed readings per question | The spine of `01-framework.md`; Tool 2 in `03-tools.md`; the 12 Questions tab of the dashboard |
| `vision-framework.pdf` | **Vision Framework breakout sessions** (© 2001 Jim Collins, with Jerry I. Porras) — core values tests, purpose tests, BHAG tests, vivid description, the Mars Group method, worked examples (Sony, HP, Granite Rock, The Teaching Company) | Tool 9 `Vision Builder` in `03-tools.md` |
| `good-to-great-diagnostic-tool.pdf` | **Good to Great® Diagnostic Tool** (© 2006 Jim Collins) — the A–F grading scheme, principle-by-principle diagnostic statements, trend analysis | The grading scheme used throughout `03-tools.md` and the dashboard's Diagnostic tab |

**Why these matter:** the worksheets in this project paraphrase and adapt them into one integrated system. When you want the depth, or the directed reading lists per principle, go to these originals.

If you ever want official print copies, facilitator versions, or licensing for broader use, get them from jimcollins.com.
