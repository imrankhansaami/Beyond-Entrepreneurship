# 03 · The Toolbox — Worksheets & Templates

*Everything the framework and the system ask you to produce, as fill-in pages. Print what you need. Keep finished tools in one folder (physical or digital) — the artifacts become your institutional memory.*

*Grading scheme used throughout (from the Good to Great Diagnostic Tool):*
- **A** — We exemplify this exceptionally well; limited room for improvement.
- **B** — We often exemplify this; there is room to improve.
- **C** — Some evidence, but our record is spotty.
- **D** — Little evidence, and we have obvious contradictions.
- **F** — We operate almost entirely contrary to this.

# Part A — See reality

## Tool 1 · Great-Company Scorecard

*Purpose: your honest baseline, once a year (and after 90 days of changes, to see the trend). Time: 60–90 minutes. Do it twice — once alone, once with your team — and compare.*

**Outputs — how great are we, really?** Grade each, then add the 3-year trend (−2 declined dramatically → +2 improved dramatically):

| Output | Grade (A–F) | Trend (−2…+2) | Evidence (one line) |
| --- | --- | --- | --- |

| Distinctive impact ("if we disappeared, who would miss us and why?") | | | |
| Lasting endurance (would it thrive without the founder?) | | | |

**Inputs — the 12 principles.** Grade each; then answer its reflection question in one honest sentence:

| # | Principle | Grade | Trend | Answer in one sentence |
| --- | --- | --- | --- | --- |

| 4 | Brutal facts (Stockdale) | | | |

## Tool 2 · The Map: Twelve Questions — the team exercise

*Purpose: disciplined thought as a leadership team; the most reliable annual agenda for becoming a learning company. Time: 60–90 minutes per question.*

**Method** (as Collins designed it): work one question per month for a year — twelve months, twelve principles. Everyone reflects individually first, then the team discusses. Never rush two questions in one session; depth is the point.

| # | Reflection for the team |
| --- | --- |
| 1 | Where are we on the journey to Level 5 leadership — and where am I? |
| 2 | Do we practice first-who — right people on the bus, and in the key seats? |
| 3 | Where must we replace the tyranny of the OR with the genius of the AND? |
| 4 | What are our brutal facts, and how well do we live the Stockdale Paradox? |
| 5 | Do we make decisions inside the three circles of our Hedgehog Concept? |
| 6 | What is our flywheel, and how far can it go? |
| 7 | Have we embraced 20-Mile March discipline in every element of the flywheel? |
| 8 | What bullets and cannonballs should we fire to renew and extend the flywheel? |
| 9 | Where should we channel our productive paranoia, to avoid the five stages of decline? |
| 10 | Have we made the shift from time telling to clock building? |
| 11 | How can we better preserve the core and stimulate progress — and do we need a BHAG? |
| 12 | What is our return on luck — good and bad — and how do we increase it? |

**Per-session template:**

```
Question of the month: ____  Date: ______  Present: __________________________

What we saw (facts, not opinions):
_______________________________________________________________
What it costs us (consequences):
_______________________________________________________________
Decision or experiment (one):
Owner: ____________  By when: _________  How we'll know it worked: __________
```

## Tool 3 · Leadership Style Self-Audit

*Purpose: the one thing that multiplies everything. Time: 45 minutes, alone, honestly; repeat twice a year.*

**Part 1 — The seven elements.** Grade each; note one concrete improvement per element.

| Element | Grade | One improvement I will make (with a date) |
| --- | --- | --- |
| Authenticity — I live the values; my behavior is the best role model in the building | | |
| Decisiveness — I decide in time; I invite disagreement before, unity after | | |
| Focus — I keep to ≤3 priorities; I protect my calendar | | |
| Personal touch — real relationships, notes, accessibility; no micromanagement | | |
| Hard + soft people skills — very high standards AND genuine positive feedback | | |
| Communication — I repeat the vision; vivid images; I call a duck a duck | | |
| Ever forward — energy, optimism, tenacity; self-improvement without workaholism | | |

**Part 2 — The M-checklist** (from the cautionary portrait in BE 2.0 ch. 3). Answer with a real example or "no":

| Warning sign | True for me? | Evidence / correction |
| --- | --- | --- |
| Values professed but contradicted by my daily actions | | |
| Indecisiveness; decisions aging on my desk | | |
| So many priorities that the team can't act | | |
| Isolation — people don't bring me bad news | | |
| Communication that is turgid, vague, vision-free | | |
| Constant criticism; positive feedback rare | | |
| Resistance to new ideas; talent draining away | | |

**Part 3 — Level 5 check (window/mirror).** Write two paragraphs, no editing:
- A recent success: where did I actually put credit? Where should it have gone?
- A recent failure: did I look in the mirror before looking around the room?

**Part 4 — The cause.** Complete: *"I lead because I serve the cause of ______."* If the sentence fills in with "being successful" or "making money," rewrite it until it doesn't.

## Tool 4 · Productive Paranoia Audit

*Purpose: find the cliff before you're near it. Time: 60 minutes, annual (or after any scary close call).*

**Part 1 — The five stages of decline.** Mark your honest position and your evidence:

| Stage | Signs to look for | Position (not here / early / real) | Evidence |
| --- | --- | --- | --- |
| 1. Hubris born of success | "We've earned this"; standards relaxed; perks creep; luck read as skill | | |
| 2. Undisciplined pursuit of *more* | Expansion outside the Hedgehog; too many initiatives; growth for its own sake | | |
| 3. Denial of risk and peril | Red flags explained away; cash warnings minimized; busy instead of honest | | |
| 4. Grasping for salvation | Silver bullets: a savior hire, a new program, a pivot as rescue | | |
| 5. Capitulation | Fade to irrelevance; the company gives up before it dies | | |

**Part 2 — The reserves.** Fill in the numbers; paranoia standard: *never leave yourself open to catastrophe.*

```
Cash reserve: ____ months of expenses (target: your worst-case storm)  Runway: ____ months
Largest customer concentration: ____%   Largest product/supplier dependency: ____%
What one event could kill us? ____________________  Our early-warning signal for it: ______
What is our red-flag mechanism, and does it work when the news is bad? ______________________
```

**Part 3 — The commitment.** One paranoia action this quarter: __________________ (owner ____, by ____).

## Tool 6 · Key-Seat Audit

*Purpose: your #1 metric — the % of key seats filled with the right people. Time: 45 minutes, quarterly (and before any big people decision).*

**Step 1 — list the key seats.** A seat is key if its holder (a) makes significant people decisions, (b) failing there could expose the company to catastrophe, or (c) success there has outsized impact. Transient names are separate from permanent roles.

| Key seat (role) | Person | Right person? (yes / not yet / no) | One-line evidence | Action + owner + date |

**Step 2 — compute.**

*Purpose: the seven questions, so loyalty and wishful thinking don't decide for you. Time: 30 minutes per person, written.*

## Tool 8 · Values-First Hiring Scorecard

*Purpose: hire for values, rigorously; keep the seat empty when in doubt. Use for every hire; mandatory for key seats.*

**The three evaluation devices** (use at least three, every time): ① two or more interviews with *different* lenses (one values-focused, one craft-focused); ② references you actually call — and ask for the story behind the rating; ③ work sampling / background / a real (paid) trial of the work.

**Candidate:** ______________  Seat: ______________  Interviewers: ____________

| Values signal (interview for these) | Evidence from the process (story, quote, work sample) | Score 1–5 |
| --- | --- | --- |
| Lives our core values — ask for stories, not adjectives ("tell me about a time...") | | |
| Window/mirror reflex — takes responsibility; gives credit away | | |
| Sees responsibility, not a job — ownership beyond the list | | |
| Self-motivated; does not need external pushing | | |
| Team reflex — would go through a wall for a peer, and has | | |
| Craft standard — proud of the quality of their own work | | |

**The decision rule:**

```
Any hard value conflict → no.  Average below ____ → no.  Doubt anywhere → no. Seat stays open.
Hired? ____  Start date: ______  Enculturation buddy: ______  90-day values check: ______
```

*(Reminder from the system: when in doubt, don't hire — carry the load until the right person appears.)*

# Part C — Vision

## Tool 9 · Vision Builder

*Purpose: choose the mountain. Not wordsmithing — goal setting. Time: one 3-hour session per part, or across three sessions; then a Mars Group pass.*

### 9a · Core values — 7 tests per candidate value

List candidate values from the founders/leaders first (5–10 candidates). Test each candidate; a value passes only if two-thirds+ of your group answers **Yes to all seven**:

| Test | V1: ______ | V2: ______ | V3: ______ | V4: ______ |
| --- | --- | --- | --- | --- |
| 1. We'd build a new organization around it, regardless of industry | | | | |
| 2. We'd want it to stand 100 years from now, whatever changes | | | | |
| 3. We'd hold it even if it became a competitive disadvantage | | | | |
| 4. People who repeatedly breach it simply don't belong here | | | | |
| 5. I'd hold it even if I weren't rewarded for it | | | | |
| 6. I'd leave a job before giving it up | | | | |
| 7. If I were set for life financially, I'd still live it | | | | |

**Watch out:** don't smuggle aspirations into values. If you *wish* you had a value (innovation, say) but don't live it, it belongs in the envisioned future, not the value list. Keep the final list ≤6. Final values: ____________________.

### 9b · Purpose — 7 tests

Draft candidate purposes (use the five whys to get from "we make X" to "why"). Test each:

| Test | P1: ______ | P2: ______ | P3: ______ |
| --- | --- | --- | --- |
| 1. Personally inspiring | | | |
| 2. Still valid 100 years from now | | | |
| 3. Expands what we might do — beyond current products/markets | | | |
| 4. Helps us decide what *not* to do | | | |
| 5. Authentic — true of us, not just nice-sounding | | | |
| 6. Would be greeted with enthusiasm (not cynicism) broadly | | | |
| 7. Proud to describe my work in its terms to my kids | | | |

**Purpose (final):** ________________________________.

### 9c · BHAG — 8 tests

| Test | Your BHAG: ______ |
| --- | --- |
| 1. Exciting to me | |
| 2. Clear, compelling, easy to grasp (Mount Everest Standard — survives rewording) | |
| 3. Connects back to the purpose | |
| 4. Exciting to a broad base of the company, not just executives | |
| 5. Undeniably big, hairy, audacious — not a convoluted statement | |
| 6. Less than 100% certain (50–70% ideal) yet fully achievable if committed | |
| 7. Achieving it requires a quantum step in capabilities | |
| 8. In 25 years we could tell whether we hit it | |

**Types that work:** targeting ("become…"), common enemy, role model, internal transformation. **BHAG (final):** ____________, horizon ____ years → **5-year base camp:** ____________.

### 9d · Vivid description

Write one paragraph — specific, concrete images and analogies, emotion, in present tense as if achieved: *"It is [year]. The company looks like this… our customers… our people… a magazine writes that…"*. Test: Does it create a picture in your mind's eye? Does it use concrete examples, not platitudes? Does it express passion? Does it make you want to be part of it? → If not, it's not vivid enough.

### 9e · Mars Group

Imagine recreating your company's best attributes on another planet — the rocket seats 5–7 people. Who do you send? (Nominate broadly; take the most-nominated; typically *not* the top officers.) They distill the drafts from 9a–9d; leaders respond afterward. Mars Group: ____________________.

# Part E — Action

## Tool 11 · Flywheel Map

*Purpose: express your business as an interlocking chain that reinforces itself, then push it relentlessly. Time: one focused session; revisit annually.*

Draw the chain (4–6 steps). Each step must feed the next, and the last must feed the first — that's what makes it a wheel:

```
[A: ____________] → [B: ____________] → [C: ____________] → [D: ____________] → back to A
```

Example shape: great customer outcomes → repeat business & referrals → economics of scale → investment in people/tools → even better customer outcomes.

```
This quarter, what pushed the wheel hardest? ______________________________
Where did we stall or lurch (doom-loop symptom)? ___________________________
Which step is currently the weakest link — and who owns fixing it? __________
```

## Tool 14 · Tactical Excellence Checklist

*Purpose: run the six-part loop deliberately. Time: 45 minutes, twice a year.*

| Step of the loop | Grade | What's actually true | Fix (owner + date) |
| --- | --- | --- | --- |
| 1. Hiring — values first; three devices; when in doubt, no | | | |

# Part F — Rhythms

## Tool 19 · Meeting Agendas Pack

*Four standing agendas. Same day, same hour, forever. Print once, laminate, reuse.*

### 19a · Weekly Focus — 60 min
```
[10] Focus check — the ≤5 priorities: on/off track; each person's ≤3 for the week
[ 5] OPUR check — every critical task has one name + a date
[10] Red flags — surprises and worries; bad news spoken early, thanked publicly
[15] Decisions — what must be decided now (timeline test); the rest get owners + dates
[ 5] Expectations — what people outside this room must hear this week, and how
[ 5] Close — one appreciation; last week's commitments, honestly
```

### 19b · Monthly Truths — 90 min
```
[20] Numbers — dashboard, cash first, then marches and priorities
[30] One brutal fact — deep dive, data, no blame, root cause, one action + owner
[15] People check — key-seat movement, hiring, overdue feedback, autopsies
[10] Bullets in flight — quick empirical read; kill or feed
[10] Appreciation — two or three specifics, values-linked
[ 5] Stop-doing enforcement
```

### 19c · Quarterly Advance — half day
```
[60] Marches first — every owner: actuals vs target, surprises
[30] Flywheel check — what pushed it; where we stalled or lurched
[45] Key seats — update map, recompute %, route every "no" through the 7 questions
[45] Bullets → Cannonballs — score, decide, protect reserves
[30] After-action on SMaC — 3 questions; change ≤1 ingredient
[30] Next quarter — marches, bullets, owners, dates
[15] Recognition — values-linked, public
[10] Decisions log — read back everything decided today
```

### 19d · Annual Reset — 1.5–2 days
```
DAY 1 — REALITY (no decisions)
  Outputs scorecard · The Map, 12 questions · The brutal facts hour (autopsy: no blame)
  Key-seat audit · Big-bet review (bullets & cannonballs) · Paranoia sweep (5 stages + cash)
  Core review — values & purpose (15 min; changing them is itself a red flag)

DAY 2 — DECISIONS
  The mountain — BHAG + 5-year base camp · Strategy refresh (bets/flanks/victories)
  The ≤5 priorities — one owner each · Marches set · SMaC reviewed (≤1 change)
  Bullets to fire · Stop-doing list · Calendar all four rhythms · The story to tell the company
```
